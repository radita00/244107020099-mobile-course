# Week 1 - Mobile Development Ecosystem & Flutter Refresh

## Tujuan

Membuat aplikasi Flutter sederhana untuk memahami kembali dasar pengembangan aplikasi mobile menggunakan Flutter.

## Fitur

- Menampilkan profil pengguna
- Menampilkan nama
- Menampilkan informasi mahasiswa
- Menampilkan foto profil
- Menggunakan layout Flutter dasar

## Teknologi

- Flutter
- Dart
- Material Design

## Cara Menjalankan

1. Clone repository
2. Masuk ke folder project
3. Jalankan flutter pub get
4. Jalankan flutter run

## Hasil

Aplikasi berhasil dijalankan menggunakan Flutter.
